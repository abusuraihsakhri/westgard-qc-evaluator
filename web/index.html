Westgard QC Evaluator

Laboratory quality-control screening · 1-2s · 1-3s · 2-2s · R-4s · 4-1s · 10x

Computes in this browser. Data are not uploaded. Use independently established control means and standard deviations.

Control data

One row per control level per run. Run identifiers are integers; duplicate run/level pairs are rejected.

SD must be positive and finite. Statistics should be determined independently of the evaluated runs.

Rule definitions and scope

1-2s is warning-only; 1-3s rejects a run. 2-2s compares two same-side 2SD excursions either within a run or across two consecutive runs of the same level. R-4s requires opposite-direction 2SD excursions within a run with at least a 4SD range. 4-1s and 10x track each control level separately across consecutive runs. If a level is absent in a run, its consecutive sequence resets. Threshold equality counts for SD limits; 10x excludes points exactly on the mean.

This supports QC review and education, not automated result release. Laboratory-specific procedures and rule selections take precedence.
